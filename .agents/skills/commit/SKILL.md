# Как делать commit

1. Посмотри '/diff'
2. Сгруппируй по логическим шагам, одно шаг - один commit
3. Формат: Conventional Commits (feat, fix, refactor, test, docs, chore)
4. Заголовок до 72 символов, в повелительном наклонении
5. Тело — только если нужно объяснить «почему», а не «что»
6. Создай коммиты
